## 更换模型时保留什么

Actions 构建、云端任务环境、Harbor 官方评分、五组框架、LangSmith、指标采集、提交归档
和案例证据可以继续使用。已有 DeepSeek 结果保留为独立模型批次。

如果后续选择 vLLM 小模型，需要单独记录模型版本、推理格式、工具调用解析、上下文和
输出预算，并重新执行新模型的解题试次。已有答案不能通过重新评分转化为小模型成绩。
不同模型跑不同任务后，不合并为一个全量准确率。

候选方案是先在原六题上做禁网、五组的 30 个小模型单元，再根据实际完成率与 GPU 耗时
决定是否扩展。此方案尚未启动，也没有申请 GPU。比较模型时，明确记录预算与运行版本差异。
