# 公共源码下载缓存

Windows 3.11 任务的镜像已包含磁盘镜像、VNC 和编译依赖；官方参考解还需下载 QEMU 5.2.0 源码，
自行编译并启动服务。准备脚本仅缓存该公开发布包，核对包内版本并记录 SHA-256，保留原来的编译和启动步骤。

联网和禁网组使用相同文件。PATH 中的下载适配器只处理列明 URL：wget 的普通下载、显式输出和
默认重名文件行为均有测试；其他参数或 URL 继续交给原 wget。已安装 curl 时也复用既有的精确 URL 适配器。
每次缓存命中记录到 `/opt/harnesslab-public-downloads/cache-hits.jsonl`，随该任务的提交文件保存。

准备过程在任务镜像中下载文件，然后关闭外网，通过原参考解形式的 wget 命令验证文件字节。
归档只包含公开下载物、校验记录和下载适配器，最终是否能编译、启动并满足测试仍由四项环境对照验证。

来源：[QEMU 5.2.0 官方发布包](https://download.qemu.org/qemu-5.2.0.tar.xz)。
