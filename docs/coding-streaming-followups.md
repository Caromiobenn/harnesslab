# Follow-up tasks after the streaming amendment

Subsequent ready tasks use the same HIGH/N1 streaming protocol as the 680-cell cohort. Their selection lists that cohort first, followed by every later cohort in order. Preparation inherits the original transport amendment, verifies the source hashes of retained actor outcomes and the canary/retirement receipts, and reserves the original adaptive-rejection-sampler attempts as well as every task queued in earlier streaming cohorts.

This keeps the six artifact-regraded API failures in their original cells and prevents readiness work from resampling already attempted or queued tasks. New arrays wait for the preceding array to terminate and retain the global two-model concurrency limit. Controls, task images, budgets and captured dependency bytes remain task-specific and immutable.
