# 终端 Agent 交付可靠性实验

两轮实验都在 WSL Ubuntu 2 的 Docker 容器中运行。模型使用阿里云百炼北京的 `deepseek-v4.1-flash-1017`，关闭思考模式。终端题为独立构造的研究任务。审计复用历史 Terminal-Bench 2.1 的任务轨迹证据。

## 第一轮

3 道题的 36 次正式运行均达标。语言任选时，预装工具链的 9 次运行都用了编译产物，需本地解包的 9 次运行有 4 次交付脚本。明确要求 C 的 18 次运行均交付可重建二进制。

36 份首个候选均达标。复查改动了 13 份提交，评分判定没有翻转。复查消耗 392,512 个 token，占该批观测用量约 69%。历史 TB2.1 中保存的正则前后版本则提供了一个可复跑的反例，复查后同一输入从 0 个匹配变为 1 个。

## 第二轮校准

4 道新题在预装工具链下各测两种交付要求，共 8 次。8 次都有评分，6 次达标。跨时区聚合的一个 C 候选通过公开样例，却在隐藏输入中遗漏部分同组事件合并。库存题的一个任选语言运行用完响应预算，没有生成首份交卷标记，冻结的末版处理同日入库和需求的顺序有误。两题的参考解在校准和正式种子下的无模型对照均达标。

## 第二轮正式矩阵

48 个单元均有有效评分，33 个通过。两次首轮请求在模型 API 断开后失效，只重跑了这两个单元。保留原尝试和观测到的 4,134 个 token。以同设置重跑结果纳入正式分母，其中一次通过、一次功能未通过。

| 题面 | 工具链 | 达标 | 功能通过且缺交付要求 | 脚本产物 |
| --- | --- | ---: | ---: | ---: |
| 明确要求 C | 已配置 | 7/12 | 0/12 | 0/12 |
| 明确要求 C | 需定位并配置 | 9/12 | 0/12 | 0/12 |
| 语言任选 | 已配置 | 8/12 | 0/12 | 0/12 |
| 语言任选 | 需定位并配置 | 9/12 | 0/12 | 9/12 |

语言任选时，有额外准备成本的一组更常交付脚本，脚本数按全部试次计数。在明确要求 C 的两个条件里，功能通过的提交都满足交付要求。4 道题、单一模型下的通过率差异提供描述性结果。

### 复查策略

11 个试次用完响应预算时还没有首份交卷标记，其中 3 个最后保存的产物达标。同轨迹策略比较覆盖其余 **37 条**。公开检查触发复查 6 次。下表的用量包含输入和输出 token。

| 策略 | 达标 | 观测 token | 耗时中位数 |
| --- | ---: | ---: | ---: |
| 直接提交首份候选 | 30/37 | 679,849 | 18.0 秒 |
| 固定复查 | 30/37 | 1,491,573 | 41.9 秒 |
| 公开检查触发复查 | 30/37 | 823,747 | 19.3 秒 |

固定复查改动了 7 份提交，出现 0 次修复和 0 次回归。与固定复查相比，按需复查的离线策略少使用 667,826 个 token（44.8%）。这批配对中，直接提交与另外两种策略同分且成本最低。按需复查耗时包含独立公开检查，并从已记录的首次交付与固定复查轨迹选取端点。未生成首份候选的试次留在正式矩阵的通过率中，策略比较中的估计限定在可配对的轨迹。

构建与评分的本地容器 ID 和源文件哈希保存在[实验汇总数据](result-summary.json)。运行环境使用 Debian Bookworm、GCC 12.2.0、binutils 2.40 和 glibc 2.36。重新构建时，基础镜像标签和 Debian 包源会随时间更新，实验清单记录了本次使用的镜像 ID。

## 历史审计

第一轮对 53 个历史候选案例和 4 个合成对照做了 171 次判断。历史案例的两项标签同时正确数在仅看动作、加入返回、加入提交证据时分别是 47/53、52/53、51/53。

第二轮冻结 27 个案例的 81 个请求，复用 22 个逐字相同的请求结果，新增 59 次判断。有效结果为 81/81。下表只比较两轮共有的 22 个历史案例。

| 可见证据 | 第一轮整理节录 | 第二轮脱敏摘录与已核验上下文 |
| --- | ---: | ---: |
| 动作 | 19/22 | 19/22 |
| 加入工具返回 | 21/22 | 22/22 |
| 加入提交证据 | 20/22 | 21/22 |

匹配组 33 项工具返回中，23 项保留了可引用的脱敏片段。其余使用已有人工复核上下文。另有一个历史中断诊断案例，已独立核验取得且使用了参考材料，保存的产物独立复评通过 7 项测试，原运行没有官方分数。匹配历史案例中只有一个确认正例。两轮结果适用于这些已定位的候选证据。
