# 用历史工具返回复测审计器

第一轮用经过整理的证据描述评测审计模型。第二轮取其中 22 个历史案例，保留原动作与参考判定，加入可公开分析的工具返回片段，比较模型在两种证据呈现方式下的判断。案例按已复核的返回类型选取，覆盖失败、空列表、项目测试、写入回执、原始题目注释和确认取得参考材料，选样时不读取模型判断。

| 样本 | 案例数 | 用途 |
|---|---:|---|
| 与第一轮匹配的历史案例 | 22 | 逐案比较两轮，其中 1 个确认取得并使用参考材料 |
| 最新快照的新增历史案例 | 1 | 补充真实的空列表案例 |
| 历史中断诊断 | 1 | 独立案例确认参考材料取得和后续使用，原任务无分，保存的产物另有独立复评 |
| 合成证据对照 | 3 | 评测别题材料、返回截断、取得材料前成品已经冻结 |

每个案例按动作、加入返回、加入提交证据三个范围独立判断。匹配组的 33 项返回中，23 项保留了可引用的片段，其余由已有复核记录提供简要上下文。引文只截取回执、结构字段和常规输出中允许保留的部分。取得材料类案例用匿名的行结构、完成状态和已核验的时间顺序表达证据。参考判定和来源哈希单独保存。

本轮共 81 个请求，其中 22 个动作请求与第一轮逐字一致，直接复用已有判断。后续需要 59 次 API 请求。结果报告列出每个证据范围的混淆矩阵、有效判断数、同一案例的判定变化，以及 22 个匹配案例的两轮正确数和方向发生变化的数量。中断诊断和合成对照单独汇总。自然正例数量适合逐案解释。

从研究目录运行。使用本机历史证据包的路径替换命令中的占位路径。`dataset/`、正文判断及来源索引属于本地实验数据，由 Git 忽略。

```bash
python3 phase2/audit/build_dataset.py --archive /path/to/local-evidence
python3 phase2/audit/run_blind.py \
  --phase1-predictions artifacts/audit-full-20261118/predictions.jsonl \
  --dry-run
python3 phase2/audit/run_blind.py \
  --phase1-predictions artifacts/audit-full-20261118/predictions.jsonl \
  --env-file /path/to/project/.env \
  --out phase2/artifacts/audit-raw
```

可用 `--phase1-dataset` 传入第一轮冻结的数据目录。第一轮的预测文件需和同一次运行的 `summary.json` 放在一起，运行器会重新计算第一轮汇总并验证数据集清单、模型和请求是否一致。
