# 四道离线终端任务

| 任务 | 主要边界 |
| --- | --- |
| `shift-reports` | 最后一次修订覆盖旧事件，UTC 跨日和负日期，半小时分桶，有符号累计 |
| `csv-reconcile` | 带逗号和双引号的 CSV，保留空格，最后的非空标签，CRLF 和末行缺换行符 |
| `inventory-aging` | 乱序事件，同日先补货，恰好到期，先进先出，按请求原顺序回报 |
| `route-ledger` | 最低费用再最少边数，平行边，零费用环，路径数取模，不可达 |

题目、正式隐藏输入和参考实现均为新建。每个任务有一个公开输入输出样例。隐藏评分结合边界输入和固定种子生成的输入，比较输出并独立验证 C 文件对应的二进制。参考解用 C 实现，判分预期输出由 Python 另算。样例检验与隐藏评分各有独立入口。

在工具链需要准备的条件下，模型从工作区说明和本地目录表识别当前架构对应的缓存包，将其解包到工作区，再运行配置命令。预装条件由执行器提前完成相同的步骤。两种条件使用同一个构建命令和编译参数。

在研究目录运行以下命令，复用首轮已构建的 actor 和评分镜像。

```sh
python3 phase2/tasks/check_controls.py --out artifacts/fixture-controls.json
```

控制检查覆盖 16 个题目与条件组合，分别验证空提交被拒、参考解通过公开样例和两个种子的隐藏输入。错误取模的 C 变体能通过公开样例，但至少一个隐藏用例会失败。功能正确的 Python 提交在语言任选时达标，在明确要求 C 时不满足交付要求。
